# [SKILL_D03] Interaction Engine (宫位生克与钥匙眼定位)

## 核心职责
基于前两步的数据，判定我方宫与对方/用神宫之间的“五行生克关系”，并从中提取出全局最致命的“钥匙眼（Key Pin）”，为最终的诊断结论和后续化解提供锚点。

## 逻辑规则要点

### 1. 大势判定决策树 (Interaction Decision Tree)
比较我方宫（日干）与对方/事态宫（时干或场景用神）的五行生克。必须带入 D02 扫描出的旺衰与空亡状态进行辩证分析：

- **时生日 (客生主) / 宫位比和**
  - *结论*：大势顺畅，对方/大势追着我成，外部资源主动倾斜。
  - *防伪排查*：若生我之宫逢**空亡**、**入墓**或**击刑/门迫**，则判定为**“假吉”**（心有余而力不足，或者纯属虚情假意画大饼）。

- **日克时 (主克客)**
  - *结论*：我方主动出击，能掌控局面，啃下硬骨头。
  - *防伪排查*：若我方处于休囚或四害状态，则为“克不动”，自不量力，反被拖累。若成功，过程也极其累人。

- **时克日 (客克主)**
  - *结论*：我方受大势/对方强力压制，阻力极强。
  - *防伪排查*：此时强行推进必败。但若克我之宫逢空亡或衰弱，则压制力大减，为“虚惊一场”。

- **日生时 (主生客)**
  - *结论*：我方主动倒贴，过度消耗自身资源去迎合对方/大势。

### 2. 锁定全局钥匙眼 (Identify the Key Pin)
**钥匙眼** 是整个奇门局中阻断能量流动的“阿喀琉斯之踵”，也是破局的关键。请执行以下排查逻辑，定位 1-2 个全局钥匙眼：

1. **生克阻断关卡**：如果在主客生克的路径上，主导宫位遇到了**空亡**或**门迫**，则该宫位就是钥匙眼（例如：通关通道逢空）。
2. **致命的直接打击**：如果有一个极凶的宫位（临庚/白虎/死门/击刑）正在**直接克制**日干宫，该凶宫就是最危险的钥匙眼。
3. **用神自刑/入墓**：如果核心用神（如求财的生门）自身**击刑**或**入墓**，则该用神宫自身就是钥匙眼。

## 输出要求
本阶段必须明确输出：
1. 核心宫位之间的生克效能。
2. 判定出全局的关键走势（顺势、逆风、僵局、虚假繁荣）。
3. 锁定全局唯一的“钥匙眼（Key Pin）”宫位及其中包含的病灶符号。
