# [SKILL_D02] Pathology Scanner (旺衰与四害病灶扫描)

## 核心职责
在 `SKILL_D01` 锁定用神宫位后，全面扫描我方宫、对方宫及核心用神宫的“能量旺衰”与内部隐藏的“病灶（四害与恶煞）”。

## 逻辑规则要点

### 1. 天时动能与气场旺衰 (Energy & Vigor)
评估用神是否有“天时”与“底气”。
- **天时动能 (九星)**：看天盘九星根据月令处于 `[旺/相]` 还是 `[休/囚/废]`。
  - **旺相**：代表外部大环境顺风、驱动力强、趋势利好。
  - **休囚废**：代表大环境逆风、无外部动能、大势已去或时机未到。
- **底气 (天干长生)**：以天干在宫位的十二长生状态（如长生、帝旺、病、绝）判定。

### 2. 四害病灶扫描与现实对标 (The Four Pests)
仔细排查核心宫位是否包含以下“四害”。若包含，必须将其“翻译”为极度写实的现代商业/现实语境：

- **门迫 (Gate Compulsion)**
  - *机制*：八门五行克落宫五行。
  - *现实对标*：战术行为做错，人与环境严重拧着，成本暴增，遭遇行政干预，物理损毁，执行层面被外力强行卡死。

- **击刑 (Stem Punishment)**
  - *机制*：六仪击刑。
  - *现实对标*：能量过旺自作死，内心极度拧巴煎熬，触犯底线/规矩，必有罚款、破财、骨折受伤或关系严重撕裂。

- **入墓 (Stem Tomb)**
  - *机制*：天干入墓库。
  - *现实对标*：能力被环境封印，昏沉找不准方向，有劲使不出；资金/信息被冻结，隐匿不报，当缩头乌龟。

- **空亡 (Void/Emptiness)**
  - *机制*：旬空。
  - *现实对标*：能量缺损，不在状态；对方画饼吹牛，纸上富贵，事情悬在半空未落地，或者代表“人迹皆空”的安全真空期。

### 3. 恶煞扫描与现实对标 (Malefic Stars/Deities)
当宫位内出现以下高能负面符号时，叠加其特定的凶险含义：

- **临 `庚金` / `白虎`**
  - *现实对标*：遇到死板无情的规则、强硬蛮横的小人卡扣、突如其来的恶意竞争、血光之灾或暴力冲突。
- **临 `天芮星` / `死门`**
  - *现实对标*：存在致命的隐患漏洞、体制内部的顽固瑕疵、沟通渠道被彻底关死（僵局）、不可调和的痼疾。
- **临 `螣蛇` / `玄武`**
  - *现实对标*：螣蛇主虚惊、时断时续、反复无常、神经质；玄武主暗耗、骗局、信息不对称、灰色地带。

## 输出要求
本阶段只提取症状，将用神宫的旺衰与四害/恶煞标签精准列出，准备进入下一阶段的生克传导分析。
