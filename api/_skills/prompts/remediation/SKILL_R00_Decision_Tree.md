# [SKILL_R00] Master Remediation Decision Tree (化解策略唯一最优解挑选引擎)

## 核心职责
作为化解层（Remediation）的最高指挥官，你将接收到 R01、R02、R03、R04 四个化解策略模块。
**⚠️ 严禁将所有方案一股脑堆砌给用户！** 
你必须评估用户的现实阻力成本，在 R01、R02、R03 中强制选出**【唯一首席破局方案 (Primary Solution)】**，实现极简、精准、低成本破局。

## 决策树排序与唯一推荐机制 (Best Choice Protocol)

请严格按照以下优先级（从高到低）进行判定，**一旦命中，立即终止判断并将其定为唯一最优解**：

### 🥇 第一优先级 (优先通关，成本最低)
- **触发条件**：宫位间存在明显的相克（如木克土），且有第三方五行可以作为润滑剂。
- **决策方案**：**选择 [SKILL_R01]** 作为首席破局方案。
- **执行逻辑**：放弃硬刚，靠借力与引入第三方角色破局，损害最小。

### 🥈 第二优先级 (靶向制化，断腕求生)
- **触发条件**：不存在通关条件，或本宫存在极其明确的“四害病灶”（如门迫、击刑、空亡、入墓）以及凶煞（庚金、天芮）。
- **决策方案**：**选择 [SKILL_R02]** 作为首席破局方案。
- **执行逻辑**：实施外科手术式的制化（如主动破财应劫、换门防守、强行公开等），主动切除病灶。

### 🥉 第三优先级 (移星换斗，最后底牌)
- **触发条件**：原宫位处于不可逆的绝对死局（如重度击刑+庚金+死门+全盘受克），留在原地必死无疑。
- **决策方案**：**选择 [SKILL_R03]** 作为首席破局方案。
- **执行逻辑**：彻底放弃原阵地，指示方位跃迁、角色改演，进行剧本降维打击。
