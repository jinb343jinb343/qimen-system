# [SKILL_R02] Pathology Remediation (四害与病灶靶向制化)

## 核心职责
当 D03 锁定的【全局钥匙眼】为四害（门迫、击刑、入墓、空亡）或极凶符号（庚金、天芮星）时触发。抛弃求神问卜，使用外科手术式的战术动作，对病灶进行精准靶向制化与现实对冲。

## 逻辑规则矩阵 (靶向战术库)

### 1. 门迫 (Gate Compulsion)
- **战术动作：【主动换门】**。
- **实操落地**：立即终止当前迫宫的行为模式。例如，若生门受迫，停止激进投资；改演 `[休门/杜门]` 的防守、内修、保密姿态。或者引入 R01 的中间五行通关来卸去压迫力。

### 2. 击刑 (Stem Punishment)
- **战术动作：【主动破财应劫】**。
- **实操落地**：能量过旺自作死，必须主动泄火放血。主动给团队发奖金、主动体检抽血、在合同中主动让利给对方以应凶象；同时寻找“六合”或“合干”角色（如乙庚合、丁壬合的对方）来强行约束自身的冲动与破坏欲。

### 3. 入墓 (Stem Tomb)
- **战术动作：【对冲引动与强行公开】**。
- **实操落地**：打破封印状态，向对冲宫位的方位采取动作（如异地出差、引入跨区/外地合作力量）。将事情强行公开化，撕破隐匿面纱（发内部公告、召开全员会、拉入第三方公证）。

### 4. 空亡 (Void/Emptiness)
- **战术动作：【虚病实做 + 等待填实】**。
- **实操落地**：绝不接受口头承诺、画大饼。必须见公章盖章、资金进入联名监管账户、拿到实体抵押物。在时间窗未到（出空填实、冲实节点）之前，按兵不动，死等应期，绝不提前下场。

### 5. 庚金 (Gen-Metal / The Destroyer)
- **战术动作：【丙火强压 / 乙奇软化 / 壬癸水泄利益】**。
- **实操落地**：
  - 用**丙火**：引入更高层领导、法律裁判或官方威慑强压对手。
  - 用**乙奇**：派柔性中间人、女性代表或情感慰问去套住对方，施展美人计/缓兵之计。
  - 用**壬癸水**：在合同里设立合法的泄洪接口，让渡部分利益把庚金的破坏欲引流走。

### 6. 天芮星 (Tian Rui / The Illness)
- **战术动作：【天心星医治 / 割肉切除】**。
- **实操落地**：寻找内部懂行的专家（天心星、乙奇）进行彻底的体制诊断、财务审计。若无药可救，当机立断执行切割，剥离亏损项目或清理毒瘤人员，绝不拖泥带水。

## 输出要求
本阶段必须明确输出针对“钥匙眼病灶”的**【战术执行手册】**，给出明确的行为指令与应对姿态调整建议。
