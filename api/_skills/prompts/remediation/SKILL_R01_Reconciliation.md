# [SKILL_R01] Reconciliation (五行通关桥梁化解)

## 核心职责
当 D03 诊断结果出现【两宫相克】（如日时相克、求测者与目标相克）的严重冲突局势时，触发本技能。必须按“损害最小、收益最大”原则，构建第三方五行通关桥梁，化解正面对抗。

## 逻辑与输出规范

### 1. 确定通关五行 (Elemental Bridge Selection)
根据相克双方的五行属性，强制引入中间态五行进行缓和：
- **金克木** ➔ 找 **水** (坎宫 / 壬癸水)。用柔水泄金生木。
- **木克土** ➔ 找 **火** (离宫 / 丙丁火)。用烈火泄木生土。
- **土克水** ➔ 找 **金** (乾兑宫 / 庚辛金)。用坚金泄土生水。
- **水克火** ➔ 找 **木** (震巽宫 / 甲乙木)。用木材泄水生火。
- **火克金** ➔ 找 **土** (坤艮宫 / 戊己土)。用厚土泄火生金。

### 2. 提取战术剧本 (Tactical Script Extraction)
将确定的通关五行与宫位转化为极度写实的现实指导方案：

#### 核心心法
**放弃硬刚，引入缓冲。** 强行推进必败，必须采用柔性润滑与利益包裹策略。

#### 人和 (行为剧本与第三方引入)
- 寻找符合**通关宫位星门神特征**的中间人介入调停。
  *(例如：若通关宫在乾宫临开门，寻找体制内高管、年长男性领导作为中间人)*。
- 改变交涉模式，采用**第三方托管 / 信托隔离 / 补充协议**模式来构建防火墙。

#### 天时与地利 (时空落地窗)
- **时间选择**：选择通关宫位地支对应的时间（特定的年、月、日、时）去接触或破冰。
- **空间选择**：谈判、签约或交涉的地点，必须选在物理空间的**通关方位**（如寻找木通关时，选择东方的茶室或木质装潢的会议室）。

## 输出要求
本阶段必须输出一套逻辑严密的【五行通关操作指南】，明确：
1. 通关所需的五行元素及对应的宫位/方位。
2. 在现实中应物化为何种角色、事件或协议机制。
3. 最佳的交涉时间窗与空间方位。
