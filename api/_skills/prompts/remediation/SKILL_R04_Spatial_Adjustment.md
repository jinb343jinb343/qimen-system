# [SKILL_R04] Spatial Adjustment (物理空间拆补移)

## 核心职责
作为所有化解方案的**强制挂载模块**。将高维的星门神干逻辑，最终降维映射到用户的现实家居、办公微环境之中。通过“拆、补、移”的手法微调物理空间的微磁场，以配合心理与行为的战术化解。

## ⚠️ 严禁神棍化原则 (STRICT REALISM)
不得推荐任何符咒、神兽、开光物件或古怪的宗教法器。
必须统一使用美观、高品位、符合现代生活的**日常家居或办公用品**（如高档台灯、阔叶绿植、实心奇石、流水茶具、金属工艺品等）。

## 物理空间调理三大手法

### 1. 【拆】 (清理病灶)
针对盘面中出现的重度病灶（天芮星、庚金、击刑、死门）所在的方位，进行物理扫除。
- **操作指令**：明确指出清理该方位的破烂杂物、发霉物品、尖锐刀具、破损金属、垃圾桶、枯死植物或闲置已久的废弃物。
- *逻辑映射*：拔除现实空间中的破坏性能量发射源。

### 2. 【补】 (填实与通关补气)
针对盘面中出现的空亡、入墓宫位，或者为了构建 R01 的“五行通关”桥梁，进行针对性的能量补充。
- **空亡/入墓** ➔ 摆放实心且有分量的物品（如实心奇石、保险柜、厚重书籍）以“填实”气场，打破空洞。
- **五行通关补充**：
  - 需补火：放置暖色常亮落地灯、红色系艺术画。
  - 需补水：放置流水茶具、加湿器、鱼缸或黑色/蓝色系摆件。
  - 需补木：摆放大叶/阔叶生机勃勃的绿植。
  - 需补金：放置高档金属钟表、圆形金属工艺品。
  - 需补土：摆放陶瓷艺术品、黄玉/奇石、方形大地毯。

### 3. 【移】 (能量场重构)
为了配合 R03 的“移星换斗”，将错置在凶位的“代表核心利益的吉祥物件”挪移回收。
- **操作指令**：将代表财运的保险柜/收款机，代表官运的印章/证书，代表健康的床头，从病灶凶方直接挪移到选定的吉方（如生门方、值符方）。

## 输出要求
本模块必须作为最终的行动指南附在诊断报告末尾，输出简短、直接的【环境风水微调清单】：
1. 明确指出哪个方位需要“拆（清理什么东西）”。
2. 明确指出哪个方位需要“补（摆放什么符合五行的现代高品位物件）”。
3. 明确指出哪些核心物品需要“移”。
